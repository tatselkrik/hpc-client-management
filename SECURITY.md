# Security Policy

## Project status

HPC Client Management is a privacy-safe public source snapshot of a privately
configured Windows clinic application. It is not a hosted service or a publicly
supported production distribution.

Security maintenance applies to the current public version, `0.3.5`. Earlier
versions are retained as project history and are not separately supported.

## Reporting a security concern

Do not disclose a suspected vulnerability, exploit details, credentials, logs,
or sensitive records in a public issue.

If a concern can be raised without sensitive details, open a minimal issue that
identifies the affected version and requests a private reporting channel. Wait
for that channel before sharing reproduction steps or technical details.

Never include real or suspected client-identifying information, health
information, clinic credentials, Supabase project references, signing material,
private updater details, backups, or unredacted screenshots in a report.

## Public-source boundary

The public repository intentionally excludes operational configuration, live
clinic data, private branding, production endpoints, deployment credentials,
signing keys, and private backups. A report that depends on private deployment
details should describe only the affected component and version until a private
channel is available.

## Response expectations

Reports will be reviewed when practical, but this personal portfolio repository
does not provide a service-level agreement, guaranteed response time, or
production support. Do not deploy it with real clinical data without an
independent security, privacy, permissions, backup, and recovery review.
